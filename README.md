# 3D 아틀라스 — 서울 · 제주 · 채플힐

OpenStreetMap 벡터타일 + SRTM 표고로 만든 인터랙티브 미니어처. Three.js 직접 렌더.

```
python3 -m http.server 8747
```

- 서울 → http://localhost:8747/
- 제주 → http://localhost:8747/?city=jeju
- 채플힐(NC) → http://localhost:8747/?city=chapelhill

오른쪽 위 **i → 도시 선택**에서도 전환할 수 있다.

## 구성

| 파일 | 역할 |
|---|---|
| `tools/build-city.mjs` | z14 벡터타일 → 경량 씬 데이터 (도시마다 한 번만 실행) |
| `app.js` | 지형·건물·나무·물·바다·도로 렌더 |
| `landmarks.js` | 도시별 랜드마크 캐리커쳐 (서울 13 · 제주 13 · 채플힐 9) |
| `index.html` | UI, 이름표 오버레이, `?city=` 분기 |
| `test/screenshot.mjs` | 정적 서버 + Playwright 스크린샷 (시각 검증용) |

## 데이터 만들기

```
npm i
node tools/build-city.mjs seoul
node tools/build-city.mjs jeju
node tools/build-city.mjs chapelhill
```

## 피복

`landcover` · `park` · `landuse` 세 레이어를 종류별로 갈라 `greens`에 `{ t, r }`로 담는다.

| `t` | 뜻 | 출처 | 바닥 | 나무 |
|---|---|---|---|---|
| 0 | 잔디·초지 | `landcover` class=grass | ○ | |
| 1 | 숲 | `landcover` class=wood | ○ | ○ |
| 2 | 골프장 | `landcover` subclass=golf_course | ○ | |
| 3 | 밭·과수원 | `landcover` class=farmland | ○ | |
| 4 | 부지 | `landuse` 묘지·학교·테마파크·운동장 등 | ○ | |
| 5 | 공원·국립공원 | `park` | | ○ |

골프장은 class가 grass라 잔디와 섞이는데, 제주에서는 세 번째로 넓은 피복이라 색을 따로 준다.
공원은 숲 폴리곤과 통째로 겹치므로 바닥을 깔지 않는다 — 깔면 둘이 깊이 경합한다.

나무만으로는 숲이 땅으로 읽히지 않는다. 바닥을 함께 깔아야 나무 밀도를 낮춰도 숲이 남는다.

## 다른 도시

`tools/build-city.mjs`의 `CITIES`에 중심좌표와 bbox를 넣고, `landmarks.js`의
`LANDMARKS_BY_CITY`에 랜드마크 목록과 빌더를 더한다. `index.html` 상단 `CITY`에는 화면 문구와
첫 시점만 적는다. 타일과 표고는 전 세계 커버.

`CITIES`의 선택 필드 — 기본값으로 두면 서울과 같이 동작한다.

| 필드 | 뜻 | 기본 | 제주 |
|---|---|---|---|
| `unit` | bin 좌표 1단위의 미터 | 1 | 2 |
| `tree` | 나무 격자 간격(m) | 34 | 68 |
| `hRef` | 지형 색 램프가 끝 색에 닿는 표고(m) | 420 | 460 |
| `gLo` | 램프에서 건너뛸 앞쪽 색 수 | 0 | 1 |
| `bRef` | 건물 색 램프가 끝 색에 닿는 높이(m) | 165 | 60 |

랜드마크는 `s: [가로, 세로]` 배율(기본 `[1.7, 2.6]`), `foot`(이 반경의 지형 최저점에 앉힌다),
`cam: [거리, 올려본각]`, `clear`(이 반경 안의 건물·나무를 지운다)로 조절한다.

## 알아둘 것

- 지형·건물 높이 3× 과장 (`EXAG`)
- 안개·시야·그림자 범위는 도시 폭에 비례해 늘어난다 (서울 = 1, 제주 = 1.82)
- UI는 `?city=`로만 갈린다. 랜드마크 목록은 오른쪽, 접을 수 있다
- **좌표 단위** — bin은 Int16이라 ±32.7km가 한계다. 폭 79km인 제주는 `unit: 2`로 저장한다
- **물** — DEM(30m)으로는 강바닥이 뭉개져 물이 묻히므로, 물 폴리곤을 마스크로 구워 그 아래
  지형을 파낸다. 바다(`class: ocean`)는 따로 모아 마스크에만 쓰고, 화면에는 수평선까지 이어진
  해수면 한 장을 편다 — 타일마다 쪼개진 폴리곤을 그대로 그리면 경계에서 z-fighting이 난다
- **섬의 가장자리** — 지형은 벡터타일 범위보다 10% 넓게 받는다. 그 여유분에는 바다 폴리곤이
  없어 해발 0m 땅으로 남으므로, 섬이면 타일 범위 밖을 통째로 바다로 친다
- **깊이 경합** — 시야가 580km까지 열리면 58km 지점의 깊이 분해능이 근평면 20에서 약 10m밖에
  안 된다. 해수면 판(y=2)과 그 위 1~13단위에 놓인 항·포구 폴리곤이 통째로 깜박였다. 셋으로 막는다.
  ① 해발 4m 미만 물 폴리곤은 그리지 않는다 — 해수면 판이 이미 같은 색으로 덮는다
  ② 해수면 아래 지형은 16m가 아니라 90m를 판다 — 해안선이 해수면 높이를 얕게 스치지 않도록
  ③ 근평면을 `20 × 축척²`로 민다 (서울 20 그대로, 제주 66)
  `test/flicker.mjs` + `test/coastdiff.py`로 카메라를 6m 흔들어 해안대 변화율을 잰다 (8.35% → 2.43%)
- 첫 로드는 표고 타일 + 데이터로 서울 약 10초, 제주 약 20초 (DEM z12 타일 96장)

### 제주 데이터의 한계

- OSM 건물 커버리지가 성기다. 제주시 도심은 z14 타일 한 장에 2,600동이 들어 있지만 한림읍은
  35동뿐이다. 서귀포·중산간은 실제보다 한산하게 보인다
- **중산간이 비어 보이는 건 OSM에 피복 데이터가 없기 때문이다.** 섬 전역 43개 육지 타일
  (179km²)을 훑으면 타일에 든 피복은 전부 합쳐 73.8km²(41%)뿐이다. 세 레이어를 모두 읽어도
  나머지 59%는 채울 것이 없다 — 제주 중산간의 목장·밭은 아직 아무도 그려 넣지 않았다
- DEM은 z12(약 38m/px), 지형 메시는 세그먼트당 약 109m다. 한라산은 제대로 읽히지만 지름
  200~300m인 오름은 거의 남지 않는다

## 미니어처 표현

- 지형·건물·랜드마크는 `miniature.js`의 공통 무광 재질을 사용한다. 수면만 거칠기를 낮춰 유약 같은 빛을 낸다.
- 낮 팔레트는 크림·세이지·청록으로 제한하고, 나무는 둥근 수관과 원뿔 수관을 인스턴싱으로 섞는다.
- 물가 테두리는 합쳐진 수면 마스크 양쪽을 검사해 타일 경계를 제외한다. 서울의 수면을 가로지르는 주요 도로에는 모형식 상판·난간·교각을 더한다. 원본 데이터에 교량 속성이 없어 실제 다리 구조를 복원하는 방식은 아니다.
- 장면에만 약한 틸트 시프트 효과를 적용한다. 중앙은 선명하고 근접 시 효과가 사라지며, UI와 이름표는 흐려지지 않는다.
- 그림자는 넓게 퍼지는 PCF 필터와 낮은 그림자 강도를 사용한다. 후처리는 `miniature.js`, 도시 팔레트와 조명은 `app.js`에서 조절한다.

### 랜드마크 모형

서울 13개 모형에 전망대 창호, 타워 입면, 문루 아치·곡선 처마, 국회의사당 열주, 경기장 관람석·지붕 등 특징을 추가했다. 작은 부품은 재질별로 병합해 그린다. 장소 선택 시 실제 모형 경계와 화면 비율을 기준으로 카메라 거리를 계산하고 모형 중앙을 바라본다.

`http://localhost:8747/test/landmark-gallery.html`에서 모형을 따로 확인할 수 있다. `?city=jeju`는 제주 모형 검수용이다. GPU를 사용할 수 있는 macOS에서는 `CITY_TEST_GPU=metal node test/screenshot.mjs ...`로 캡처할 수 있다.

### 작은 도시 장면과 이동 조작

`city-life.js`는 광화문 앞 모형식 광장(포장·벤치·분수·가로등), 한강 유람선 2척, 교량 경로 위 차량 최대 24대, 일부 건물의 박공지붕·옥상 정원·옥탑, 야간 창문 조명을 만든다. 건물 디테일은 인스턴싱하고 가로등의 빛 번짐은 점 스프라이트를 사용한다. 배는 수면 마스크 안의 경로, 차량은 도로 상판과 같은 좌표를 따라 움직인다. 실제 운항·교통 정보나 광장 시설 배치를 재현하는 기능은 아니다. 모션 줄이기 설정에서는 배와 차량이 정지한다.

마우스: 왼쪽 드래그는 회전, **Space 또는 Shift를 누른 채 왼쪽 드래그**와 오른쪽 드래그는 이동, 휠은 확대·축소다. Space 해제 또는 창 포커스 상실 시 회전 조작으로 돌아간다.

지도 위에서 왼쪽 버튼을 같은 자리(6px 허용)에서 **1초간 누르면 임시 이동 모드**가 켜진다. 누른 채 바로 드래그해도 이동하며, 커서는 `grab`/`grabbing`으로 바뀐다. 이동 드래그 중 움직이거나 드래그를 마칠 때마다 3초 타이머를 갱신하고, 3초간 이동하지 않으면 회전 모드로 복귀한다. Space 이동은 독립적으로 유지하며 창 포커스 상실·포인터 취소 시 임시 모드를 해제한다. `pan-gesture.js`가 제스처와 타이머를 관리하고 `MapControls.setMouseGesture`가 누르고 있는 OrbitControls 제스처를 전환한다. Three.js 버전을 올릴 때 내부 state/초기화 메서드 호환성을 확인해야 한다. `CITY_TEST_GPU=metal node test/pan-gesture.mjs`로 길게 누르기·이동·자동 복귀·기존 키 조작을 검증한다.

오른쪽 아래 나침반은 카메라 회전에 맞춰 N·E·S·W 방향을 표시한다. 클릭하거나 키보드로 선택 후 Enter를 누르면 현재 중심·거리·기울기를 유지한 채 북쪽을 위로 맞춘다. 자동 비행은 중단한다. `compass.js`가 방향 표시와 550ms 회전을 처리하며, 모션 줄이기 설정에서는 즉시 맞춘다. `CITY_TEST_GPU=metal node test/compass.mjs`로 방향·시점 보존·키보드·모바일·야간을 검증한다.

아이폰 Safari에서 **기울여 보기**를 누르고 동작·방향 센서 접근을 허용하면 현재 자세를 기준으로 시점이 움직인다. 좌우 최대 30°, 상하 최대 18°로 제한하고 작은 손떨림은 완화한다. 이 모드에서는 한 손가락 드래그로 이동하고 두 손가락으로 확대·축소한다. **시점 맞추기**로 편한 자세를 다시 기준으로 잡는다. 터치 이동·자동 비행·나침반 조작을 우선하며, 화면 방향이 바뀌면 현재 시점에서 다시 기준을 잡는다. 버튼을 다시 누르거나 탭을 백그라운드로 보내면 모드를 종료한다.

센서 사용에는 **HTTPS 접속**이 필요하다. PC의 개발 서버를 아이폰에서 `http://192.168.…:8747`로 여는 것만으로는 사용할 수 없다. 미지원·권한 거부·센서 신호 없음은 안내 메시지로 표시한다. `device-look.js`가 센서와 카메라 연동을 담당한다. `CITY_TEST_GPU=metal node test/device-look.mjs`는 모의 센서로 권한 처리, 시점 제한, 터치 이동·확대, 재설정, 화면 회전, 나침반 연동과 모바일 UI를 검증한다. 실제 아이폰 하드웨어에서의 감도와 권한 동작은 별도로 확인해야 한다.

개발 서버 실행 후 `CITY_TEST_GPU=metal node test/city-life.mjs`로 낮/밤 재생성, 서울·제주 장면, 이동 애니메이션, 실제 Space 드래그·키 해제·포커스 상실 동작을 검증한다.

### 즉각적인 이동과 드래그 품질

`map-controls.js`는 고정된 Three.js 0.185.1의 OrbitControls에서 누적 이동량만 즉시 적용한다. 회전 감속은 유지하며 Space/Shift/오른쪽 드래그에 같은 규칙이 적용된다. `_panOffset` 내부 필드를 사용하므로 Three.js 버전을 올릴 때 `test/controls-response.mjs` 검증이 필요하다.

조작 중에는 픽셀 비율을 최대 1로 낮추고 초점 후처리를 생략하며 그림자 위치를 고정한다. 조작 종료 120ms 후 기존 해상도·후처리를 복원하고 필요한 그림자를 갱신한다. 사용자 조작이 시작되면 진행 중이던 카메라 비행도 중단한다.

개발 서버 실행 후 `CITY_TEST_GPU=metal node test/controls-response.mjs`로 세 이동 방식의 즉각 반영·잔류 이동 없음, 회전 감속, 그림자 고정, 화질 복원을 확인한다.

### 확대 시 주변 장소 이름표

`neighborhood-labels.js`는 카메라가 가까워질수록 산·주요 공원·대학, 역·시장·문화시설, 작은 공원·명소 순서로 주변 이름표를 추가한다. 이름표를 누르면 해당 장소로 이동하고 장소 종류와 좌표를 표시한다. 기존 이름표 버튼으로 함께 켜고 끈다.

서울 5,667개, 제주 1,084개, 채플힐 516개의 POI를 포함한다. 기본 데이터는 지도와 동일한 OpenFreeMap / OpenStreetMap 2026-08-30 스냅샷에서 추출했다. OSM에 수록된 장소 기준이며 실시간 정보나 모든 시설을 포함하지 않는다. 데이터 재생성은 `node tools/build-pois.mjs seoul|jeju|chapelhill`에서 원하는 도시 하나를 인자로 넣어 실행한다.

호텔은 가까운 확대 단계(거리 2,600 이하), 백화점은 중간 확대 단계(4,600 이하)에서 나타난다. 분류는 OSM 태그 기준이다. 제주의 해수욕장 9곳은 벡터타일 POI에 이름이 없어 제주관광공사 [Visit Jeju](https://www.visitjeju.net/)의 이름·지도 좌표로 보완했다. 각 원문 링크는 `data/jeju.beaches.json`에 보존한다. `node tools/build-jeju-beaches.mjs` 실행 후 제주 POI를 재생성하면 갱신된다.

로컬 JSON을 한 번 읽고 공간 격자로 주변 후보를 찾는다. 이름표는 UI와 서로의 영역을 피해 데스크톱 최대 20개, 모바일 최대 9개만 표시한다. 배치 계산은 120ms 간격이며 표시 중인 이름표 위치는 매 프레임 갱신한다. POI 로드가 실패해도 기존 랜드마크는 표시한다.

개발 서버 실행 후 `CITY_TEST_GPU=metal node test/neighborhood-labels.mjs`로 확대 단계, 이름표 겹침, 선택·이동, 밤 테마, 표시 토글, 동네 전환, 모바일 표시 수, 제주 POI를 검증한다.

### 노스캐롤라이나 채플힐

UNC 캠퍼스·프랭클린 스트리트·인접 카보로를 포함한 약 13.5×14.5km 범위를 담는다. 북쪽 경계를 35.995°까지 넓혀 Eubanks Road와 모리스그로브 학교를 포함한다. z14 타일 64개에서 건물 27,804동과 숲·도로·수계를 생성했으며, 지형 타일을 제외한 저장 데이터는 약 2.03MB다. 올드 웰, 모어헤드–패터슨 종탑, 윌슨 도서관, 모어헤드 천문관은 흰 열주·벽돌·돔을 강조한 모형이다. 위치는 OSM POI와 [Old Well 좌표](https://www.wikidata.org/wiki/Q7085397)를 참고했다. 서경 좌표는 W로 표시한다.

`CITY_TEST_GPU=metal node test/cities-and-pois.mjs`로 채플힐 모형·장소 선택·야간·모바일 도시 전환, 제주 해수욕장·호텔 확대 단계, 서울 백화점 클릭을 확인한다.

채플힐에서는 학교 28곳, 마트 21곳과 카페·음식점·약국·편의점·가게도 표시한다. 학교·마트는 중간 확대, 소규모 가게는 가까운 확대 단계에서 나타난다. 모리스그로브 초등학교는 정식 랜드마크이며, 오른쪽 ‘동네 둘러보기’에는 Chapel Watch Village와 해리스티터 채플힐 노스 바로가기가 있다. Chapel Watch Village는 [단지 공식 지도](https://chapelwatchvillage.com/neighborhood/)의 공용 위치로 보완하며, 원본은 `data/chapelhill.places.json`에 기록한다. 특정 개인의 거주지 정보는 포함하지 않는다.


채플힐 랜드마크에 The Farm 테니스 클럽, Ballet School of Chapel Hill, Chapel Hill Public Library, Dean Smith Center·Koury Natatorium을 추가했다. 테니스 코트·클럽하우스, 스튜디오 창과 바, 도서관의 유리 입면·차양, 낮은 돔과 수영·다이빙 풀을 표현한다. 쿠리 수영장은 내부가 보이도록 지붕을 생략한 모형이며 실제 개방형 수영장이 아니다. 실측 복원이 아니라 장소의 특징을 강조한 미니어처다.

위치·시설 확인: [The Farm 공식 안내](https://uncfarm.org/the-farm/contact-us/), [The Farm 지도 좌표](https://maps.roadtrippers.com/us/chapel-hill-nc/sports/the-farm-at-unc), [발레스쿨 공식 안내](https://www.balletschoolofchapelhill.com/), [발레스쿨 OSM 위치](https://mapcarta.com/W44325853), [공공도서관 설계](https://www.ramsa.com/expertise/project/chapel-hill-public-library), [다이빙 클럽 시설 안내](https://ncdivingclub.com/content/facility), [쿠리 수영장 위치](https://mapcarta.com/26734478). 공공도서관 좌표는 기존 OSM POI와 동일하다.

모리스그로브 초등학교는 OSM의 학교 위치에 낮은 벽돌 교실동, 창, 푸른 입구 차양, 작은 운동장을 단순화한 모형을 둔다. 랜드마크로 승격해 일반 POI 이름표는 중복 표시하지 않는다. The Farm 모형 중심은 OSM 테니스 코트 군집(-79.00565, 35.89368)에 맞춰 진입로와 겹치지 않도록 잡았다. 목록이 길어지면 내부 스크롤하며 나침반 공간을 남긴다.
